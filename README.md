# NASA-Dashboard-Project
Hello!

This is my submission for the 2026 Summer NASA Stardance Challenge

This is a 90s style dashboard, featuring the following

A earth observation window, with NEOs orbiting a earth made out of dots!
A banner text sporting the dashboards name
Orbits being drawn either when you a click a NEO or you toggle the button,
A console log featuring endless lines of text
All of the information about a neo at the click of a button
A system uptime counter
A display window when you click the neo
A time speed manipulator, allowing it to simulate faster or slower

And a bunch more!
Thanks for reading, be sure to check it out!
